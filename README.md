# Документация разработчика

## Обзор проекта
Проект разработан на **Godot Engine**. Структура проекта организована по модульному принципу с разделением сцен, скриптов и компонентов.

## Структура директорий
- `res://scenes/` — Основные сцены игры (меню, уровни, игровые объекты).
  - `menu/` — Сцены главного меню и интерфейсов.
  - `game/` — Сцены игрового процесса и UI.
- `res://levels/` — Сцены уровней (`level_1.tscn`, `game.tscn`).
- `res://scripts/` — Глобальные скрипты и утилиты.
- `res://components/` — Переиспользуемые компоненты (коллайдеры, навыки и т.д.).

## Запуск и отладка
1. Стартовая сцена: `res://scenes/menu/menu_control.tscn`.
2. При нажатии кнопки "Play" загружается уровень `res://levels/level_1.tscn`.

## Система логирования ошибок
В проект встроен автоматический регистратор ошибок для упрощения отладки.

### Принцип работы
- Узел `DebugLogger` (скрипт `res://scripts/debug_logger.gd`) добавлен в корень стартовой сцены (`menu_control.tscn`).
- При каждом запуске проекта старый файл логов удаляется, и создается новый чистый файл.
- Перехватываются все системные сообщения: ошибки (`push_error`), предупреждения (`push_warning`) и отладочный вывод (`print`).

### Расположение логов
Файл сохраняется в пользовательской директории проекта:
```
user://debug_errors.log
```
Чтобы открыть папку с логами во время отладки в редакторе Godot:
1. Запустите проект.
2. В верхнем меню выберите **Debug** → **Open User Data Folder**.
3. Найдите файл `debug_errors.log`.

### Программное использование
Из любого места кода можно вручную записать событие, получив доступ к узлу (например, через уникальное имя или передачу ссылки):
```gdscript
# Пример ручного логирования
DebugLogger.log_error("Критическая ошибка в механике прыжка")
DebugLogger.log_warning("Ресурс загружен с задержкой")
DebugLogger.log_message("Игрок подобрал бонус")
```

## Известные особенности
- Пути к ресурсам в `.tscn` файлах используют текстовые пути вместо UID для совместимости.
- Убедитесь, что все скрипты, подключаемые в сценах, физически существуют по указанным путям, чтобы избежать ошибок парсинга при загрузке.
